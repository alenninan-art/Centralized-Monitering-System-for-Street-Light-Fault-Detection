# Centralized-Monitering-System-for-Street-Light-Fault-Detection

A streetlight fault monitoring system built with React, TypeScript, and Vite.

## Development

Install dependencies with `npm install`, then start the development server with `npm run dev`.

Create a production build with `npm run build` and run lint with `npm run lint`.

## Vite and React

This project uses the Vite React plugin with Oxc. The React Compiler is not enabled by default because of its impact on build performance. To add it, see the [React Compiler documentation](https://react.dev/learn/react-compiler/installation).

For type-aware Oxlint rules, install `oxlint-tsgolint` and enable the `typeAware` option in `.oxlintrc.json`.
